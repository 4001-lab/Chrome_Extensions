AI Support Assistant

A production-deployed Chrome extension that helps customer support agents generate intelligent, context-aware replies using RAG and real-time order data — instantly.

🧠 Groq · Llama 3.3 70B 🔷 Google Gemini Embeddings 🗄️ Supabase (PostgreSQL) ☁️ Vercel Serverless 🌐 Chrome Extension MV3
Problem Statement

Customer support agents spend significant time crafting replies manually, often inconsistent, slow, and disconnected from live order data — leading to poor customer experience and high agent workload.

⏱️Slow response times due to manual lookup across multiple tools
📋Inconsistent answers — agents rely on memory or outdated docs
🔍No quick access to order status during live customer chats
🔄Repetitive effort for common queries (refunds, tracking, cancellations)

Key Features
🧠
RAG-Powered Responses
Retrieves the most relevant knowledge base entries using vector similarity before generating any reply — grounding answers in real policy data.
Gemini Embedding-001
⚡
Real-Time Streaming
Responses stream token-by-token via Server-Sent Events, giving agents instant feedback without waiting for the full reply to generate.
SSE · Groq API
📦
Live Order Lookup
Agents enter an Order ID and the backend fetches live order status, items, and customer name from Supabase to personalise the reply.
Supabase PostgreSQL
🌐
Chrome Extension UI
Lightweight MV3 popup — no page reload, no tab switching. Agents stay in their support tool while generating AI replies in a side panel.
Manifest V3
☁️
Serverless Deployment
Backend runs as a Vercel serverless function — zero server management, auto-scaling, and globally distributed edge delivery.
Vercel · Node.js ESM
🔒
Grounded & Safe Prompting
Prompt template strictly instructs the LLM to answer only from retrieved context. If no relevant data exists, it politely declines — no hallucinations.
